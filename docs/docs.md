# CONFLICTO ENTRE RAMAS
Modificación realizada desde la Rama A para probar conflictos.

Modificación competidora realizada desde la Rama B.

El conflicto se generó al editar la misma línea del archivo README.md en dos ramas distintas (A y B).
Se fusionó primero la Rama A a main y, al integrar la Rama B, se resolvió manualmente seleccionando la versión final deseada en GitHub.
De esta manera, se sincronizó el historial de commits y se completó el flujo de integración continua sin pérdida de datos.
